# Job Card UI — React

A clean and minimal job card UI built with **React.js and Vite**.
This project was created as part of my React learning journey, focusing on component structure, CSS styling, icons, and building a UI from a design reference.

## Preview Single card UI

![Job Card Preview](./Prop/public/Result.png)


## Features

-  Clean and minimal job card design
-  Built with React.js
-  Powered by Vite
-  Save icon using Lucide React
-  Job title and company information
-  Job type and experience level tags
-  Salary and location information
-  Apply Now button
-  Responsive-friendly structure


## Technologies Used

- React.js
- Vite
- JavaScript
- CSS
- Lucide React
- HTML
